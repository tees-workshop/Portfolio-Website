# Tehilah Okhiria — Portfolio

A personal developer portfolio built with **Next.js App Router, TypeScript, Tailwind CSS v4, and Framer Motion**.

## Run locally

Requirements: Node.js 20 or later recommended.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

## What's included

- Responsive single-page portfolio with About, Projects, Experience, Skills, and Contact sections
- Light/dark theme toggle that remembers the selected theme
- Motion effects with reduced-motion support
- Project links to GitHub repositories and available live demos
- Contact form that prepares an email draft in the visitor's mail application

## Before deploying

- Review all project descriptions and make sure they accurately represent the project's features and your contribution.
- Add the final résumé PDF to `public/resume.pdf` and add a visible download link once the file is ready.
- Add your preferred public contact email. The contact form currently opens an email draft without pre-filling a recipient.
- Replace the generic LinkedIn destination with your actual profile URL.
- Confirm the Novo live URL and whether it can be shown publicly.
- Check the Vercel project settings and ensure the project uses the `redesign/nextjs-portfolio` branch for preview before merging to `main`.
